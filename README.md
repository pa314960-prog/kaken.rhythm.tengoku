# リズミカ！ (Rhythmica)

リズム天国ライクな、**ブラウザだけで動くリズムゲーム**です。
インストール不要・ビルド不要・通信不要。フォルダをコピーするだけで、どのパソコンでも動きます。

**公開URL: https://pa314960-prog.github.io/kaken.rhythm.tengoku/**

## 1. 動作環境

| 項目 | 内容 |
|---|---|
| OS | Windows 10 / 11（Mac・Linuxでも動きます） |
| ブラウザ | **Chrome / Edge の最新版**（Firefoxも可） |
| 必要なもの | **なし**（Node.js も Python も必須ではありません） |
| 通信 | 不要（オフラインで完結します） |
| 音 | スピーカーかイヤホン。**イヤホン推奨**（音のズレが少ない） |

## 2. 起動のしかた（2通り。どちらでもOK）

### 方法A：いちばん簡単（ダブルクリック）

1. このフォルダを開く
2. **`index.html`** をダブルクリック
3. ブラウザが開いたら、画面をクリックして開始

これだけです。

### 方法B：ローカルサーバーで起動（おすすめ）

1. **`start.bat`** をダブルクリック
2. 黒い画面が出て、ブラウザが自動で `http://localhost:8000/` を開きます
3. 遊び終わったら、黒い画面で `Ctrl + C` を押すか、そのまま閉じる

Python が入っていない場合は、自動的に方法Aと同じ動作（直接開く）に切り替わります。

<details>
<summary>なぜ方法Bのほうが良いの？</summary>

`index.html` を直接開く（`file://`）と、ブラウザのセキュリティ制限が強くかかります。
このゲームは制限に引っかからないよう作ってあるので方法Aでも遊べますが、
将来ファイルを追加したときのトラブルを避けたい場合は方法Bが安全です。
</details>

## 3. 他のパソコンで動かす（3つの方法）

### 方法1：フォルダごとコピーする（いちばん確実）

1. このフォルダ全体を右クリック →「送る」→「圧縮 (zip 形式) フォルダー」
2. できた ZIP を、USBメモリ・メール・OneDrive などで相手のPCへ渡す
3. 相手のPCで **展開（解凍）してから** `index.html` か `start.bat` を実行

> ⚠️ ZIPの中身を直接ダブルクリックしないでください。必ず展開してから開きます。
> （展開しないと CSS や JS が読み込まれず、真っ白な画面になります）

### 方法2：同じネットワーク内の別PCから遊ぶ

1. ゲームを置いたPCで `start.bat` を実行
2. そのPCで `cmd` を開き `ipconfig` を実行して、IPv4アドレス（例 `192.168.1.5`）を調べる
3. 別のPCのブラウザで `http://192.168.1.5:8000/` を開く

> つながらない場合は、Windows ファイアウォールで Python の通信を「許可」してください。

### 方法3：GitHub Pages で公開する（URLを配るだけ）

このリポジトリには公開用の設定 (`.github/workflows/pages.yml`) が入っています。

1. GitHub のリポジトリページ → **Settings** → 左メニューの **Pages**
2. **Source** を **GitHub Actions** に変更して保存
3. `main` ブランチに push する（または Actions タブから `Deploy to GitHub Pages` を手動実行）
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` で誰でも遊べます

## 4. 遊び方

* 使うボタンは **1つだけ**：`Space` / `Enter` / `Z` キー、または**画面クリック・タップ**
* 右から流れてくる音符が、左の**マトに重なった瞬間**に押す
* 緑の帯（ながおしノート）は**押しっぱなし**にして、**終わりでパッと離す**
* `Esc` キーでいつでも中断できます

| 判定 | 意味 |
|---|---|
| ジャスト | ドンピシャ（±55ミリ秒） |
| ナイス | 少しズレ（±115ミリ秒） |
| ミス | 大きくズレた・押し忘れた |

**コツ：目で追うより、音のノリに合わせるほうが当たります。**

### ステージ

| # | ステージ | 内容 | BPM |
|---|---|---|---|
| 1 | 🥁 タイコ道場 | 表拍だけの入門編 | 118 |
| 2 | 📣 コール＆レスポンス | お手本を聴いて、同じリズムでまねっこ | 126 |
| 3 | ⚙️ ウラビート工場 | ウラ拍中心＋ながおしノート | 138 |

## 5. 音がズレて感じるときは（重要）

パソコン・ブラウザ・イヤホンによって、音が出るまでの遅れは変わります。
タイトル画面の **「タイミング調整」** で自動補正できます。

1. タイトル →「タイミング調整」
2. 「計測スタート」を押す
3. 「カッ、カッ」の音に合わせて **8回以上** ボタンを押す
4. 測定結果が出たら **「この値を使う」** を押す

Bluetoothイヤホンは遅延が大きい（100〜200ミリ秒）ため、**必ず調整してから**遊んでください。
手動で微調整したい場合は「設定」の**判定オフセット**を動かします（プラス＝遅めに押してもジャストになる）。

## 6. ファイル構成

```
.
├── index.html          画面の骨組み（ここを開けば動く）
├── start.bat           Windows用の起動ファイル
├── start.sh            Mac / Linux 用の起動ファイル
├── css/
│   └── style.css       見た目（外部フォント・画像は不使用）
└── js/
    ├── storage.js      設定とハイスコアの保存
    ├── audio.js        音の合成 ＋ リズム用スケジューラ ★心臓部
    ├── input.js        キー・マウス・タッチの受付と時刻計算
    ├── stages.js       ステージ定義（譜面・伴奏・絵）
    ├── game.js         判定・スコア・描画
    ├── ui.js           画面遷移・タイミング調整・リザルト
    └── main.js         起動処理
```

**音声ファイルは1つもありません。** すべての音は Web Audio API でその場で合成しています。
そのためフォルダをコピーしても音が欠けることがなく、容量もほぼゼロです。

## 7. 譜面を追加・改造する

`js/stages.js` の `build()` の中を書き換えるだけです。
**1行 = 1小節 = 16文字（16分音符）**で書きます。

| 文字 | 意味 |
|---|---|
| `x` | プレイヤーが押すノート |
| `H` と `-` | ながおし（`H---` なら1拍ぶん伸びる） |
| `o` | お手本（自動で鳴る。押さない） |
| `.` | 休み |

```js
build: function () {
  return parse(8, [          // 8 = 8拍目から始める（前奏2小節ぶん）
    'x...x...x...x...',      // 4分音符で4回
    'x.x.x.x.x.......',      // 8分音符で4回 → 休み
    'H-------..x...x.'       // 2拍ながおし → ウラ拍で2回
  ]);
}
```

ステージを丸ごと増やしたい場合は、`stage1` の形をコピーして
`id` / `name` / `bpm` / `build` などを書き換え、最後の `var list = [stage1, stage2, stage3];` に追加します。

## 8. 困ったときは

| 症状 | 原因と対処 |
|---|---|
| 画面が真っ白 | ZIPを展開せずに開いている。**展開してから** `index.html` を開く |
| 音が出ない | 最初の「画面をクリックしてスタート」を押していない。ブラウザの仕様で、1回クリックしないと音を鳴らせません |
| 音が小さい／出ない（2回目以降） | ブラウザのタブがミュートになっていないか確認（タブを右クリック →「サイトのミュートを解除」） |
| リズムがズレる | 「タイミング調整」で補正。Bluetoothイヤホンは特に必要 |
| `start.bat` が一瞬で閉じる | フォルダのパスに特殊文字が含まれている可能性。デスクトップ直下など、単純な場所に置いて再実行 |
| 動きがカクつく | 他のタブ・アプリを閉じる。ブラウザのハードウェアアクセラレーションを有効に |
| ハイスコアが消えた | 記録はブラウザごとに保存されます。別のブラウザ・別PC・シークレットウィンドウでは引き継がれません |
